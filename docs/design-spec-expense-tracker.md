# Design Spec: เว็บแอปบันทึกรายรับ-รายจ่าย
### แนวคิด "Liquid Glass" โทนขาว-ฟ้า

---

## 1. แนวคิดการออกแบบ (Design Thesis)

เงินเป็นเรื่องที่คนส่วนใหญ่รู้สึกเครียดเวลาต้องเผชิญหน้ากับตัวเลข ดีไซน์นี้จึงเลือกใช้ภาษาภาพของ **"กระจกที่ลอยอยู่เหนือน้ำนิ่ง"** — พื้นผิวโปร่งแสง เบลอเบา ๆ ให้ความรู้สึกเบา สงบ ไม่กดดัน เหมือนกำลังมองข้อมูลผ่านผิวน้ำใส ไม่ใช่มองผ่านสเปรดชีตที่แข็งกระด้าง

หัวใจของหน้า Dashboard คือ "ยอดคงเหลือวันนี้" ลอยเด่นอยู่บนการ์ดกระจกใบใหญ่ที่สุด ล้อมรอบด้วยการ์ดกระจกใบเล็กที่แสดงหมวดหมู่ค่าใช้จ่าย — เหมือนฟองอากาศขนาดต่าง ๆ ที่ลอยอยู่ในน้ำ

---

## 2. ฟีเจอร์ที่ควรมี (Feature Set)

### 2.1 ฟีเจอร์พื้นฐาน (Must-have)
- บันทึกรายรับ/รายจ่าย (จำนวนเงิน, วันที่, หมวดหมู่, บันทึกย่อ)
- จัดการหมวดหมู่แบบกำหนดเองได้ (อาหาร, เดินทาง, ที่พัก, บันเทิง ฯลฯ)
- สรุปยอดคงเหลือ/ยอดรวม รายวัน-รายเดือน-รายปี
- ระบบล็อกอิน/ยืนยันตัวตน (แยกข้อมูลตามผู้ใช้)
- แก้ไข/ลบรายการย้อนหลัง

### 2.2 วางแผนงบประมาณรายเดือน (Monthly Budget Planning)
- ตั้งวงเงินที่ตั้งใจใช้ต่อหมวดหมู่ (เช่น อาหาร 5,000 บาท)
- เทียบ "งบที่ตั้งไว้" กับ "ยอดที่ใช้จริง" แบบ real-time พร้อม progress bar (เขียว-เหลือง-ส้ม)
- แจ้งเตือนเมื่อใช้จ่ายเกิน 80% / 100% ของงบในหมวดนั้น

### 2.3 ยอดคงเหลือและการมองอนาคต (Balance & Forecasting)
- คำนวณยอดคงเหลือ: รายรับเดือนนี้ − รายจ่ายเดือนนี้
- ยกยอดคงเหลือสะสมจากเดือนก่อนหน้ามาต่อเนื่อง
- กราฟเปรียบเทียบยอดคงเหลือย้อนหลัง 6–12 เดือน เพื่อดูแนวโน้ม
- พยากรณ์ยอดคงเหลือปลายเดือนจากอัตราการใช้จ่ายเฉลี่ย
- จำลองสถานการณ์ (What-if) เช่น "ถ้าลดค่าอาหาร 20% จะเหลือเงินเท่าไหร่"
- ตั้งเป้าหมายการออม แล้วระบบคำนวณว่าต้องลดรายจ่ายหมวดไหนเพื่อให้ถึงเป้า
- สรุปต้นเดือน: เดือนที่แล้วใช้เกินงบกี่หมวด พร้อมคำแนะนำ

### 2.4 การวิเคราะห์และแสดงผล (Analytics)
- กราฟสรุป: pie chart แยกตามหมวดหมู่, line/bar chart แนวโน้มรายเดือน
- เปรียบเทียบรายรับ-รายจ่ายระหว่างเดือน

### 2.5 ความสะดวกในการใช้งาน (Convenience)
- นำเข้า/ส่งออกข้อมูล (Excel/CSV) เพื่อสำรองหรือวิเคราะห์เพิ่มเติม
- รองรับหลายบัญชี/กระเป๋าเงิน (เงินสด, บัตรเครดิต, บัญชีธนาคาร)
- รายการที่เกิดซ้ำอัตโนมัติ (ค่าเช่า, ค่าสมาชิกรายเดือน)
- ค้นหา/กรองรายการตามวันที่ หมวดหมู่ หรือจำนวนเงิน
- Responsive design ใช้งานได้ทั้งมือถือและเดสก์ท็อป

### 2.6 ฟีเจอร์เสริม (Nice-to-have)
- แจ้งเตือนผ่าน notification/email เมื่อใช้จ่ายเกินงบ
- แนบรูปใบเสร็จ
- ระบบเป้าหมายการออมเงิน (saving goals)
- Dark mode (ปรับโทนกระจกให้เข้ากับพื้นหลังเข้ม)
- แชร์รายงานสรุปเป็น PDF

## 3. Color Tokens

| Token | Hex | การใช้งาน |
|---|---|---|
| `--bg-gradient-top` | `#EAF4FC` | บนสุดของพื้นหลัง gradient |
| `--bg-gradient-bottom` | `#D6EAF9` | ล่างสุดของพื้นหลัง gradient |
| `--glass-surface` | `rgba(255,255,255,0.55)` | พื้นผิวการ์ดกระจก (ใช้คู่กับ backdrop-blur) |
| `--glass-border` | `rgba(255,255,255,0.8)` | ขอบบาง ๆ ให้กระจกดูมีขอบสะท้อนแสง |
| `--accent-primary` | `#2E7FE0` | สีฟ้าหลัก — ปุ่ม, กราฟเส้น, ไอคอนสำคัญ |
| `--accent-deep` | `#144C8C` | ฟ้าเข้ม — ตัวเลขสำคัญ, ข้อความเน้น |
| `--accent-mint` | `#8FDDD4` | ฟ้าอมเขียว — สถานะ "ปกติ/ดี" |
| `--accent-warn` | `#F5A97F` | ส้มพีชนวล — สถานะ "ใกล้เกินงบ" (ไม่ใช้แดงจัด เพื่อคงความสบายตา) |
| `--text-primary` | `#1B2A3D` | ข้อความหลัก |
| `--text-muted` | `#5C7086` | ข้อความรอง/คำอธิบาย |

**หลักการ:** ไม่ใช้สีแดงจัดแม้ในสถานะ "เกินงบ" — ใช้ส้มพีชแทน เพราะเป้าหมายคือทำให้ผู้ใช้รู้สึกสบายใจกับการวางแผนการเงิน ไม่ใช่รู้สึกผิดหรือถูกตำหนิ

## 4. Typography

| Role | Font | น้ำหนัก/ขนาด |
|---|---|---|
| Display (ยอดเงินตัวใหญ่) | **Space Grotesk** | 600, ตัวเลขแบบ tabular-nums, ขนาด 40–56px |
| Heading | **Space Grotesk** | 500, 20–28px |
| Body | **IBM Plex Sans Thai** | 400, 15–16px (รองรับภาษาไทยชัดเจน) |
| ตัวเลข/ข้อมูล (utility) | **IBM Plex Mono** | 400, ใช้ในตาราง รายการ ธุรกรรม |

เหตุผล: Space Grotesk มีเส้นโค้งมนแบบ geometric ที่ให้ความรู้สึก "อ่อนแต่ทันสมัย" เข้ากับความนุ่มของกระจก ส่วน IBM Plex Mono ช่วยให้ตัวเลขจำนวนเงินเรียงชิดกันแบบตารางอ่านง่าย ไม่สับสนเลขหลักหลักพัน-หมื่น

## 5. Layout Concept

Dashboard หลักแบ่งเป็น 3 ชั้นความลึก (layer) เหมือนกระจกลอยซ้อนกัน:

```
┌─────────────────────────────────────────────┐
│  [โลโก้]         สวัสดี, ชื่อผู้ใช้      [⚙][👤]│ ← Nav บาง โปร่งแสงสุด
├─────────────────────────────────────────────┤
│                                               │
│   ╭───────────────────────────────╮          │
│   │   ยอดคงเหลือเดือนนี้            │  ← Hero glass card
│   │   ฿ 12,450                     │    (ใหญ่ที่สุด, ลอยสูงสุด)
│   │   รายรับ 25,000 - รายจ่าย 12,550│          │
│   ╰───────────────────────────────╯          │
│                                               │
│  ╭──────────╮ ╭──────────╮ ╭──────────╮      │
│  │ อาหาร     │ │ เดินทาง   │ │ บันเทิง   │  ← การ์ดหมวดหมู่
│  │ ███░░ 64% │ │ █████ 105%│ │ ██░░░ 40% │    (กระจกใบเล็ก)
│  ╰──────────╯ ╰──────────╯ ╰──────────╯      │
│                                               │
│   ╭───────────────────────────────╮          │
│   │  กราฟแนวโน้ม 6 เดือน (เส้นฟ้า)   │          │
│   ╰───────────────────────────────╯          │
│                                               │
└─────────────────────────────────────────────┘
```

- พื้นหลังเป็น gradient ฟ้าอ่อนนิ่ง ๆ ไม่ใช้สีขาวล้วน เพื่อให้กระจกมี "อะไรให้สะท้อน"
- การ์ดแต่ละใบมี `backdrop-filter: blur(20px)` + เงานุ่ม (soft shadow) เพื่อให้ดูลอยจริง
- ระยะห่างระหว่างการ์ดกว้างกว่าปกติเล็กน้อย ให้ความรู้สึก "หายใจได้" ไม่อึดอัด

## 6. Signature Element: "Liquid Light Sweep"

องค์ประกอบที่จดจำได้ของดีไซน์นี้คือ **แสงสะท้อนบนกระจกที่ไหลตามการ์ด** — เวลาผู้ใช้ scroll หรือ hover การ์ดกระจก จะมีแถบแสงสีขาวจาง ๆ ไหลผ่านผิวการ์ดแบบ subtle (คล้ายแสงตกกระทบผิวน้ำ) ใช้เฉพาะกับ **การ์ด Hero ยอดคงเหลือ** เท่านั้น เพื่อไม่ให้เกิดความรกจากแอนิเมชันซ้อนกันหลายจุด

```css
.hero-card::before {
  content: '';
  position: absolute;
  background: linear-gradient(115deg, transparent 30%, rgba(255,255,255,0.4) 50%, transparent 70%);
  animation: sweep 6s ease-in-out infinite;
}
```

## 7. Component Guidelines

**การ์ดกระจก (Glass Card)**
- `border-radius: 24px`
- `backdrop-filter: blur(20px) saturate(160%)`
- ขอบบาง 1px สีขาวโปร่ง เพื่อจำลองขอบกระจกสะท้อนแสง

**แถบความคืบหน้างบประมาณ (Budget Bar)**
- ปกติ (< 80%): `--accent-mint`
- ใกล้เกิน (80–100%): ไล่เฉดไปทาง `--accent-warn`
- เกินงบ (> 100%): `--accent-warn` เข้มขึ้น + ไอคอนแจ้งเตือนเล็ก ๆ (ไม่ใช้สีแดง)

**ปุ่ม (Button)**
- ปุ่มหลัก: พื้นสี `--accent-primary` ตัวอักษรขาว, hover ให้เงาฟ้านุ่มขยายเบา ๆ
- ปุ่มรอง: กระจกใส ขอบฟ้าบาง ตัวอักษร `--accent-deep`

**กราฟ (Charts)**
- เส้นกราฟใช้ `--accent-primary` พร้อม gradient fill โปร่งแสงด้านล่างเส้น (area chart)
- ไม่ใช้สีสันจัดจ้านหลายสีในกราฟเดียว — ใช้ความเข้ม-อ่อนของฟ้าไล่เฉดแทนสีต่างกัน เพื่อความสบายตา

## 8. Motion & Accessibility

- แอนิเมชันทั้งหมดใช้ `ease-in-out`, ระยะเวลา 400–600ms ไม่เร็วกระตุก
- เคารพ `prefers-reduced-motion`: ปิด Liquid Light Sweep และลด transition เหลือ fade เฉย ๆ
- Contrast ของตัวอักษรบนพื้นกระจกต้องผ่านมาตรฐาน WCAG AA (ทดสอบเฉพาะจุดที่ข้อความทับพื้นหลัง gradient เข้ม)
- Focus state ของปุ่ม/อินพุตต้องเห็นชัดเจน (ring สีฟ้าเข้ม `--accent-deep` หนา 2px)

---

## 9. Empty & Error States

- หน้าว่าง (ยังไม่มีธุรกรรม): ข้อความชวนลงมือ เช่น "ยังไม่มีรายการเดือนนี้ — เริ่มบันทึกรายการแรกกันเลย" พร้อมปุ่มเพิ่มรายการ
- เกินงบประมาณ: ข้อความบอกตรง ๆ ไม่มีอารมณ์ตำหนิ เช่น "หมวดเดินทางใช้เกินงบที่ตั้งไว้ 100 บาท" พร้อมทางเลือกปรับงบหรือดูรายละเอียด
